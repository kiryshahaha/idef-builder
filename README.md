# IDEF Builder — Веб-редактор диаграмм по ГОСТ Р 50.1.028-2001

Интерактивное веб-приложение для проектирования диаграмм семейства **IDEF (IDEF0, DFD, IDEF1X, IDEF3)** с полным соблюдением отечественных государственных стандартов:
* **ГОСТ Р 50.1.028-2001** («Информационные технологии поддержки жизненного цикла продукции. Методология функционального моделирования IDEF0»)
* **ГОСТ 19.701-90** / нотация Gane-Sarson (Схемы данных и диаграммы DFD)
* **РД ИР 50.1.026-2001** (Методология IDEF1X, реляционные базы данных в 3NF)
* **Р 50.1.031-2001** (Методология структурного анализа и моделирования процессов IDEF3)

---

## 🚀 Быстрый запуск

1. Дважды кликните по файлу **`start.bat`** (или выполните `python server.py`).
2. В браузере автоматически откроется интерфейс по адресу:
   ```
   http://localhost:8080/index.html
   ```
*(Приложение полностью автономно и работает без подключения к интернету).*

## 📐 Особенности и соблюдение ГОСТа

1. **Официальный координатный бланк (Мастер-страница, Приложение А ГОСТ Р 50.1.028-2001):**
   * Верхний штамп: *«Используется в:»*, *«Автор»*, *«Проект»*, *«Замечания: 1 2 ... 10»*, *«Версия»*, даты и время ревизий, матрица статусов (*Рабочая версия*, *Проект*, *Рекомендовано*, *Публикация*), *«Читатель»*, *«Контекст»*.
   * Нижний штамп: *«Узел»*, *«Заголовок»*, *«Номер»*, *«Стр.»*.
2. **Семантическая дифференциация стрелок ICOM:**
   * **Входы (Inputs):** синий цвет `#1e40af`, входят строго с левой грани блока.
   * **Управления (Controls):** фиолетовый цвет `#7c3aed`, входят строго с верхней грани.
   * **Выходы (Outputs):** тёмно-синий цвет `#1e293b`, выходят строго с правой грани.
   * **Механизмы (Mechanisms):** красный цвет `#dc2626`, входят снизу вверх.
   * **Стрелки вызова (Call):** красный цвет, направлены вниз.
3. **Ортогональная маршрутизация 90° (п. 5.3.2):**
   * Все линии изгибаются только под прямым углом 90°, никаких диагоналей.
4. **Встроенный ГОСТ-Контроль (Автовалидатор):**
   * Проверка правила 3–6 блоков для диаграмм декомпозиции (п. 8.1).
   * Проверка глагольных наименований функций (п. 6.1).
   * Запрет технических ICOM-слов в наименованиях стрелок (п. 6.3.д).
   * Контроль полноты заполнения штампа.

## 🎨 Готовые шаблоны из коробки

В кнопке **«Шаблоны»** доступны полностью преднастроенные диаграммы лабораторной работы №3 по проекту **Samarov Studio**:
1. **IDEF0 A-0:** Контекстная диаграмма (блок А-0, входы, управления 63-ФЗ/СНиП, выходы, механизмы).
2. **IDEF0 A0:** Диаграмма декомпозиции (диагональ А1, А2, А3, А4 с интерфейсной балансировкой).
3. **DFD Уровень 1:** Потоки данных (Внешние сущности Клиент/Поставщики/Банк, Процессы 1..6, Накопители D1..D6).
4. **IDEF1X:** Логическая схема базы данных (10 сущностей в 3-й нормальной форме 3NF, первичные и внешние ключи, идентифицирующие и неидентифицирующие связи).
5. **IDEF3:** Алгоритм выполнения основного процесса (единицы работы UOB J1.1..J1.5, соединения AND/XOR, цикл доработки по SLA ≤ 2 правок).
6. **Чистые бланки** для создания собственных моделей с нуля.

## 💾 Экспорт и сохранение

* **SVG (ГОСТ):** генерация чистого векторного SVG-файла со шрифтом Times New Roman и штампами по ГОСТу для вставки в Word и курсовые работы.
* **PNG (300 DPI):** растровое изображение высокой четкости (масштаб 2x) для отчетов.
* **Сохранить / Открыть (.json):** сохранение всего проекта на диск и возможность продолжить редактирование в любой момент.
* **Печать (Ctrl+P):** вывод на принтер или сохранение в PDF в альбомном формате A4.

## ⌨️ Горячие клавиши

* `Delete` / `Backspace` — удалить выделенный элемент или стрелку.
* `Ctrl + Z` — отменить действие (Undo).
* `Ctrl + Y` / `Ctrl + Shift + Z` — повторить действие (Redo).
* `Ctrl + S` — сохранить проект в `.idef.json`.
* `Двойной клик по фигуре` — быстрое редактирование текста на месте.
* `Колесо мыши` — масштабирование (Zoom 30% .. 250%).
* `Пробел + перетаскивание мыши` (или средняя кнопка) — панорамирование холста (Pan).
